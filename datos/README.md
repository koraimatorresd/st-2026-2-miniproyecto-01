# datos

La serie del grupo va en esta carpeta, en CSV. Llene esta ficha y borre la
serie de ejemplo cuando ya no la use.

| Campo | Valor |
|---|---|
| Archivo | cemento_colombia |
| Qué mide | 	Información mensual sobre los despachos nacionales de cemento gris en Colombia, expresados en toneladas.|
| Fuente | Departamento Administrativo Nacional de Estadística (DANE), https://www.dane.gov.co/index.php/estadisticas-por-tema/construccion/estadisticas-de-cemento-gris/historicos-estadisticas-de-cemento-gris?utm_source=chatgpt.com |
| Licencia | Datos Abiertos del Gobierno de Colombia / DANE (Licencia de uso libre para fines académicos citando la fuente oficial)|
| Frecuencia | mensual |
| Periodo | Abril de 2009 a agosto de 2026 (209 observaciones) |
| Columna de fecha | Fecha |
| Columna que se pronostica | Despachos_Nacionales |

## Serie de ejemplo

`air_passengers.csv`: pasajeros mensuales de una aerolínea entre 1949 y 1960,
la serie clásica de Box y Jenkins, tomada de Kaggle
(`rakannimer/air-passengers`). Solo sirve para comprobar que el guion corre;
el miniproyecto se hace con la serie del grupo.
